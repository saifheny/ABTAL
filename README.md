# Abtal (أبطال) — 3D Action-Adventure Platformer

Play directly in your browser (desktop & mobile) and install as a **Progressive Web App (PWA)**:

- **Live Web / PWA URL:** https://saifheny.github.io/ABTAL/
- **Repository:** https://github.com/saifheny/ABTAL

## Branches
- `main`: Full Godot 4.7.2 source project (`GDScript`, 3D assets, shaders, audio, localization, and Web PWA export preset).
- `gh-pages`: Ready-to-serve static WebAssembly / WebGL2 PWA build (`index.html`, `.wasm`, `.pck`, `.manifest.json`, `.service.worker.js`, and icons).

## Installing as a Mobile / Desktop PWA
1. Open `https://saifheny.github.io/ABTAL/` in Chrome, Edge, Samsung Internet, or Safari.
2. Tap **تثبيت / Install** on the in-page prompt or choose **Add to Home Screen / Install app** from your browser menu.
